KRISPY CATEGORY PAGE TEMPLATE

Files:
- index.html: category page markup
- styles.css: responsive styling
- script.js: category switching, search, sorting, filters, saved offers, promo-code copy, and load-more behavior

The pages folder is created by these files on the gh-pages branch.
Open pages/index.html to preview the category page.

Replace the sample offers array in script.js with your coupon API or database data.
The newsletter form is front-end only; connect it to an email marketing provider/backend before collecting subscribers.
The View deal action is a demo until merchant destination URLs are added.
Promo-code clipboard access generally requires HTTPS or localhost.
